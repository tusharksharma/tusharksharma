## Filenames

House documents keep their familiar names. Framework documents use `FRAMEWORK__skill-name__original-path.md` to avoid collisions between files such as `SKILL.md`. References and supporting instruction documents are flattened the same way.

Relative Markdown links between included instruction documents have been updated to their flat filenames. Backtick paths, executable examples and references to non-document assets still refer to the original installed skill or video workspace. Scripts and media assets are not duplicated here.

This is a portable snapshot, not a second live source of truth. Use the original hub for continuing updates and regenerate this flat version when needed. Current user instructions and applicable agent instructions take precedence over historical examples.
