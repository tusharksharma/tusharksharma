# ImageGen brief

Use built-in ImageGen through the available imagegen skill. This is a prompt template, not tool argument names. Supply selected actual reference files using the supported attachment/reference mechanism.

## New reaction cover

```text
Use case: ads-marketing
Asset type: The Split Plate [16:9 YouTube main thumbnail / 9:16 vertical cover].
Primary request: Photoreal integrated thumbnail for [exact premise].
Input1 REAL identity anchor [file]: Tushar, same person; preserve facial proportions, age, skin tone, eyes, nose, jaw and hair.
Input2 REAL alternate angle/expression [if useful]: identity and mouth anatomy support.
Input3 ACTUAL dish/action frame [file]: factual authority for food, ingredients, portions, packaging and result.
Input4 APPROVED GENERATED example [if useful]: composition/energy only, not identity or dish authority.
Expression: [story-specific emotion], staged thumbnail illustration; distinguish from [recent covers].
Composition: Prominent head and shoulders, minimal torso, actual food clearly recognizable, one coherent scene. [No hands unless useful.]
Light/color: Warm natural/editorial; believable skin and food. Warm-black #15120F, cream #FFFAF0, at most one lime #D8F36A type emphasis.
Text verbatim: "[supported 2–5-word hook]". Bold compact sans-serif; no giant opaque panel over food.
Constraints: Fresh expression/outfit allowed, recognizable identity fixed. Natural mouth/teeth; no enlarged, uniform, over-white or malformed teeth. No extra hands, detached limbs, unsupported bowls, invented ingredients/results. No portrait divider, unrelated people, watermark. [Verified POV • XTRA ATTO badge only if applicable.]
Framing: [Portrait critical copy x100–980/y160–1610 at1080×1920 and central grid crop / landscape safe from UI overlays].
```

## Focused likeness repair

```text
Edit target: [candidate image].
Real identity authority: [bundled real files].
Change only [specific drift: proportions/eyes/mouth/teeth/hair]. Match the REAL sources more closely. Preserve approved food, headline, layout, palette and unrelated details. Do not use the rejected generated face as identity authority. Save a versioned candidate for review.
```

For source-expression preservation, request that exact real angle/expression. For a fresh reaction, describe the change while fixing identity. Never impose a blanket closed-mouth requirement. Save final prompt and reference roles in the active project's receipt. No paid voice, upload or schedule authorization is implied.
